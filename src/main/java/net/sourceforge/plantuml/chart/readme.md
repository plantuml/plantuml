# Directory Documentation for `chart`

## Description
This package provides classes used to manage [Chart Diagrams](https://plantuml.com/chart-diagram).

## Reference
- [Chart _(on Wikipedia)_](https://en.wikipedia.org/wiki/Chart)
- [Mermaid's XY Chart](https://mermaid.js.org/syntax/xyChart.html)
- [Mermaid's Pie Chart](https://mermaid.js.org/syntax/pie.html) and [Radar Chart](https://mermaid.js.org/syntax/radar.html), for `pie` and `radar` ([#3011](https://github.com/plantuml/plantuml/issues/3011))
